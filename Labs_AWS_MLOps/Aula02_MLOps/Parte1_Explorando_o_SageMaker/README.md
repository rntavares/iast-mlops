# Parte 1 — Caça ao Tesouro no Console (sem código)

Esse lab é 100% console — o objetivo é reconhecer onde cada peça do MLOps vive na AWS.

Abra o [console do SageMaker](https://console.aws.amazon.com/sagemaker/) e:

1. **SageMaker Studio** → abra o Studio e localize o menu **Experiments** na barra lateral.
2. **Model Registry** → encontre e liste os grupos de modelo existentes (deve aparecer o `churn-model-group` se você fez a Aula 01).
3. **SageMaker Pipelines** → veja se há algum pipeline criado na conta.
4. **Feature Store** → confira se está disponível na sua conta/região.
5. Preencha a tabela abaixo relacionando cada tela com o nível de maturidade MLOps (0, 1 ou 2) visto na aula.

| Tela | O que faz | Nível de maturidade associado |
|---|---|---|
| Experiments | | |
| Model Registry | | |
| Pipelines | | |
| Feature Store | | |

Não tem gabarito único — o objetivo é a discussão em sala sobre por que cada ferramenta existe.
